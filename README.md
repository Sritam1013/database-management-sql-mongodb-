# 🧠 Student Record Management System (SQL + MongoDB)

## 📌 Overview
A database management project that demonstrates how to handle and synchronize data between **MySQL** (relational) and **MongoDB** (non-relational) databases using Python.

---

## 🚀 Features
- Create, Read, Update, Delete (CRUD) operations
- SQL schema with normalization
- MongoDB for unstructured data
- Python connectivity using `pymysql` & `pymongo`
- Can be extended with Flask web interface

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Databases:** MySQL, MongoDB  
- **Libraries:** pymongo, mysql-connector-python, pandas, flask (optional)
